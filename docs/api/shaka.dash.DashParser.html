SUPPORTED_ESSENTIAL_PROPERTIES_ :Set<string>

The set of EssentialProperty scheme URIs recognized by the parser. This is the single source of truth for EssentialProperty support and is used to: - enforce the MPD-level conformance rule of ISO/IEC 23009-1 clause 5.8.4.8 (if an MPD-level EssentialProperty, or a group sharing the same id attribute, uses only schemes outside this set, the presentation must be terminated); and - decide in parseAdaptationSet_ whether an unrecognized EssentialProperty makes the containing AdaptationSet unusable. Keep this in sync with the scheme handling in parseAdaptationSet_ and parseRepresentation_. Schemes that are recognized but intentionally ignored (e.g. MatrixCoefficients, pattern:2024, urlparam:2025) are listed here without dedicated handling.
