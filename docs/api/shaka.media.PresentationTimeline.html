programDateTimeRegions_ :Array<{start: number, pdt: number}>

A sorted (by start) list of program-date-time regions. Each region maps a presentation-time boundary, created at a discontinuity that introduces a new PROGRAM-DATE-TIME base, to the wall-clock time at that boundary. This lets us report an accurate playhead date across discontinuities (e.g. SSAI or live restarts) even though the presentation timeline itself is kept continuous. Only populated when there is at least one such discontinuity; otherwise we fall back to |initialProgramDateTime_|.

lockStartTime()

Lock the presentation timeline's start time. After this is called, no further adjustments to presentationStartTime_ will be permitted. This should be called after all Periods have been parsed, and all calls to notifySegments() from the initial manifest parse have been made. Without this, we can get assertion failures in SegmentIndex for certain DAI content. If DAI adds ad segments to the manifest faster than real-time, adjustments to presentationStartTime_ can cause availability windows to jump around on updates.
