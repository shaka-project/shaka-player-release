timeForWallClock(wallClock) → {number}

The presentation time of the media encoded at a wallclock time, in seconds, or null when the timeline cannot say. The answer comes from the latest record encoded at or before that time, advanced by however long after it the time falls: media time and wallclock time run at the same rate, which is also how wallClockForTime() interpolates. That holds past the newest record too, so a time the timeline has not reached yet still has an answer. Records whose wallclock time is 0 -- not known -- are skipped.
